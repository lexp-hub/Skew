# Skew

Minimalist open-source AI text humanizer on Cloudflare Workers.

## Features

- **Workers AI Native**: Runs on edge GPUs (`@cf/meta/llama-3.3-70b-instruct`) or offline heuristics.
- **Multi-Provider**: Cloudflare AI, Groq, OpenAI, Anthropic, Gemini, OpenRouter, local Ollama.
- **Word-Level Diff**: Visual addition/deletion inspector.
- **Metrics**: Real-time burstiness, lexical diversity, and AI cliché stripper.
